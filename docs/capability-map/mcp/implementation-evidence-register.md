## Reading rules

- `✔️` means the named boundary is implemented and directly covered by the
  cited local evidence; it does not claim semantic producer composition or
  packaged-client delivery.
- `🌗` means a real subset exists but the named outcome is incomplete or has
  an explicit environment/client boundary.
- `❌` means the in-scope owner boundary was inspected and the MCP outcome was
  not found. The owner source may still exist as an unconnected consumer.
- `⏸️` is a recorded scope hold. `not-verified` and `environment-unavailable`
  are evidence states, not implementation successes or failures.
- Paths in the register are repository paths inspected in this checkout.
  `no MCP adapter` is intentional evidence of a missing integration, not a
  substitute for a source path.
