# Release candidate — RelGeo 0.5.2

**Status:** Planned
**Recorded at:** 2026-11-26
**Compatibility line:** `0.5`
**Publication mode:** manual dengan autentikasi npm 2FA/passkey
**Snapshot:** [`0.5.2.json`](./0.5.2.json)

## Keputusan

Ini adalah candidate patch release yang membawa perubahan nyata setelah package
registry tertinggal dari source workspace. Public integration lokal memasang
package registry dengan sukses, tetapi consumer test gagal karena beberapa
package registry belum memuat kontrak yang sedang dipakai source dan fixture
terbaru. Candidate ini menjaga compatibility line `0.5` dan tidak mengubah
kontrak DSL secara breaking.

Package yang direncanakan untuk dipublish, sesuai urutan dependency:

1. `@relgeo/geometry@0.5.1`
2. `@relgeo/core@0.5.3`
3. `@relgeo/renderer-svg@0.5.1`
4. `@relgeo/language-service@0.5.2`
5. `@relgeo/remark-relgeo-hl@0.5.1`
6. `@relgeo/remark-relgeo@0.5.1`
7. `@relgeo/cli@0.5.1`

`playground` dan `relgeo.github.io` adalah consumer dan tidak dipublish ke npm
dalam release ini.

## Gate sebelum publish

- [ ] candidate record dan source revision diaudit
- [ ] build dan tarball audit lulus
- [ ] strict baseline dan compatibility lulus
- [ ] local integration gate lulus
- [ ] `npm pack --dry-run` setiap package ditinjau
- [ ] operator sudah login npm dengan 2FA/passkey

## Gate setelah publish

- [ ] registry verification seluruh package lulus
- [ ] public integration lulus
- [ ] record diperbarui menjadi `completed`, atau `partial` jika publish berhenti
- [ ] tidak ada package yang dipublish ulang dengan versi sama

Candidate ini belum merupakan klaim bahwa package sudah tersedia di registry.
Publish tetap dilakukan manual oleh operator setelah preflight ditinjau.
